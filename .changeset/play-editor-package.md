New package `@hello-eme/play-editor`: the configuration editor as a React component and a drop-in script (`editor.js`), usable without Payload; `@hello-eme/play-payload` now wraps it. New in the editor: quick settings and a simple mode, presets as cards that can be tried in the live preview, a balance check with a practice bot, problems shown at their field with a jump to it, a flow view of what triggers what, picture drag-and-drop with size and sheet detection, undo and redo, reset per tab, JSON download and load, and a searchable guide. The schema package generates the configuration reference (`buildReference`, `referenceMarkdown`; `docs/REFERENCE.md` and `docs/REFERENCE.de.md`).
