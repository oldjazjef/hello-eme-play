Configure the game with one JSON

The editor below is one script and one call, with no framework and no CMS. Change a setting and the game next to it restarts with your configuration.

1. Change somethingDrag a quick setting or pick a preset. The balance check answers in a moment.
2. Watch the previewThe game in the preview plays every change. Walk with ← → ↑ ↓, punch with Space.
3. Take the JSONCopy it below, or play it on a full page. Expert mode shows every setting; the guide explains them.

Use the game on your own page

The game is one script, play.js (attached to every release). The page it runs on is the playing field, and the JSON this editor makes is its configuration. 

<!-- the configuration: a file, or inline with data-config='{...}' -->
<script src="/play.js" data-config-url="/play.json" defer></script>

<!-- optional: your own start button (the script adds a floating one by itself) -->
<button type="button" data-play-toggle>Play</button>

Paste the JSON from above into play.json, or let your CMS serve it. {} is already a complete game with all defaults. Elements with data-play-ui are left alone by the game; data-toggle="off" removes the floating button. 

// window.Play controls it from your own code
Play.start();               Play.stop();            Play.toggle();
Play.configure(json);       // new settings, applied at once where possible
Play.setPath('/projects');  // single-page apps: pick the per-page settings

// with a bundler instead of the script tag
import { createPlay } from '@hello-eme/play';
createPlay({ config }).start();

Every setting is in the guide. The game page of this demo is exactly this: play.js plus the configuration from the editor.

Use the editor on your own page

<div id="editor"></div>
<script src="editor.js"></script>
<script>
  PlayEditor.mount(document.getElementById('editor'), {
    value: await (await fetch('/play.json')).json(),
    onChange: (json) => save(json)   // e.g. PUT it to where play.json comes from
  });
</script>

editor.js is attached to every release too. The editor shows the game in its preview by itself; give it previewUrl to preview a page of your own instead. With Payload CMS the plugin @hello-eme/play-payload puts this editor into the admin.
